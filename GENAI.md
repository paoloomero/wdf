# Use of generative AI in WDF

_Status: 28 October 2026._

WDF is developed by Paolo Omero (infoFACTORY) with extensive use of generative
AI. This file says what was generated, with which models, and how to tell
generated content apart from content written by people.

## Summary

The idea of the format and its central guarantee come from the maintainer's
concept paper of January 2026. Since this repository was created (18 July
2026), essentially everything in it was produced by Claude (Anthropic) through
Claude Code: the maintainer set the goals and requirements, took the design
decisions and approved every change, but the code and text themselves were
written by the model. Treat all content up to and including commit `7bfc77d`
(21 October 2026) as AI-generated.

The format and the tools contain no AI model. The MCP server
(`packages/mcp`) is an interface that AI agents can use; it does not run one.

## What was produced with generative AI

- **Code and tests**: all packages (`core`, `import`, `cli`, `viewer`, `mcp`,
  `extension`), scripts and CI configuration.
- **Specification**: the WDF Core 0.1 draft (`spec/wdf-core-0.1.md`) and the
  JSON Schemas, written from the maintainer's concept paper and decisions.
- **Documentation**: READMEs, `docs/`, the example documents in `examples/`
  and the copy of the website (wdf.dev).
- **Design**: the visual design of the website and of the Reader, from
  handoffs produced with Claude Design; the feature illustrations in
  `brand/illustrations/`, generated with Claude Design in a style the
  maintainer directed and selected.

Models, as recorded in the commit trailers: Claude Fable 5, Claude Fable 5.1,
Claude Opus 5.5.

## How to tell what is generated

Every commit whose content was produced with generative AI carries a trailer
naming the model:

```
Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>
```

All commits up to `7bfc77d` carry it. To list them:

```sh
git log --grep='Co-Authored-By: Claude' --format='%h %ad %s' --date=short
```

## Rules for contributions

From 28 October 2026:

1. A commit or pull request containing content produced by generative AI
   (code, tests, text, images) says so with a `Co-Authored-By:` trailer
   naming the model and its version. Pull request descriptions say it too.
2. A commit without such a trailer declares that its content was written by
   a person. Generative AI may have been used read-only (reviewing, explaining,
   running checks, pointing out flaws); the author wrote every line. Read-only
   use is recorded with a `Reviewed-with: <model>` trailer.
3. A part of the project funded under rules that exclude generative AI is
   written by people under rule 2, and this file names it.

## Pre-existing generated content

Content generated before a human-written replacement exists stays in the
repository, marked as AI-generated by its commits and by this file. When a
human-written version replaces a generated one (for example a later version
of the specification), this file will record it.
